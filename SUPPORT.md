# Support

## Bugs

Open an issue with a minimal reproduction, the exact command, operating system, Python version, expected behavior, and actual output. Use synthetic data and remove secrets.

## Usage questions

Read the [documentation index](docs/README.md), [board reference](skills/bot-orchestrator/references/board.md), and [troubleshooting guide](docs/troubleshooting.md). If a question remains, open a usage issue explaining your host, available tools, goal, and the step that is unclear.

## Host compatibility

Include the host name and version, skill import method, invocation syntax, and a concrete result. Distinguish successful discovery from successful task execution. Do not describe an untested host as supported.

## Scope

This repository does not provide hosted model access, credential recovery, paid account support, desktop drivers, or a guaranteed response time. External services are supported by their respective maintainers.
